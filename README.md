# Quest Hotels homepage

The root `index.html` and `assets/` are the production build served automatically by GitHub Pages from `main`.

To edit locally: copy `source/index.html` to root `index.html`, run `npm ci` and `npm run dev`. After changes, run `npm run build` and copy `dist/index.html` and `dist/assets/` to the repository root before committing. The original brand SVGs are in `public/assets/`.
